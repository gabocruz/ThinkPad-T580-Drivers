# Mi Script

Este script sirve para instalar los controladores adecuados para una  laptop  ThinkPad  T580
se debe hacer la instalacion despues de la instalacion del sistema operativo, el script agrega
los repositorios correspondientes para poder instalar los controladores necesarios

## Hardware del equipo
Marca: Lenovo
Modelo: ThinkPad T580

Procesador: Intel(R) Core(TM) i7-8650U CPU @ 1.90GHz
Virtualizacion: VT-x

Graficos: Intel Corporation UHD Graphics 620

Ethernet: Intel Corporation Ethernet Connection (4) I219-LM

WiFi: Intel Corporation Wireless 8265 / 8275
      Intel Corporation Dual Band Wireless-AC 8265

Storage: nvme0n1
